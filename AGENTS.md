# Studio design protocol

Before any design work for the studio or a client:

1. Pull the latest version of this repository.
2. Read `docs/design-principles.md` in full.
3. Read the approved core of the specific client brand.
4. Treat every significant element as functional and relational; never add filler.
5. Keep client-specific identity and assets in that client's repository, not here.

`docs/design-principles.md` is the canonical shared method for identity, brandbooks, interfaces, websites, decks, print, content systems, and other studio design work.
