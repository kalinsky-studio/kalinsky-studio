# Дизайн-система — Миша Калинский

Два контекста на одной базе:

- **BASE (моно)** — страница-схема workflow (`/`). Чистый ч/б брутализм.
- **SELL (лайм)** — продающая страница (`/offer`). База + кислотный акцент, мягче линии.

Все значения — из продакшен-кода (`app/workflow.css`, `app/offer/offer.css`).
Адаптив построен на `clamp(min, vw, max)` — в Figma это пара значений Mobile/Desktop.

## 1. Цвета

### Токены

| Токен | Значение | Роль |
|---|---|---|
| `bg` | `#0a0a0a` | Фон всего |
| `fg` | `#ffffff` | Основной текст, заголовки |
| `muted` | `#a3a3a3` | Вторичный текст (описания, параграфы) |
| `faint` | `#555555` | Третичный: подписи, номера, неактивное |
| `line` | `#262626` | Границы и разделители (SELL) |
| `line-hard` | `#ffffff` | Границы (BASE): 3px секции, 1px внутри |
| `accent` | `#D4FF3F` | Кислотный лайм (только SELL): CTA, акценты, маркеры |
| `accent-ink` | `#0a0a0a` | Текст поверх accent |

### Производные от accent

| Использование | Значение |
|---|---|
| Подсветка колонки таблицы | `rgba(212,255,63,0.06)` |
| Свечение в hero (radial) | `rgba(212,255,63,0.07)` |
| Тень кнопки при hover | `rgba(212,255,63,0.25)` |
| Фон карточки при hover | `#111309` |
| Selection (выделение текста) | фон `accent`, текст `#0a0a0a` |

**Правило:** акцент — только один. Лайм не используется в длинном тексте, только: CTA, eyebrow-нумерация, маркеры списков, одна строка в H1, цена апсейла, подсветка «моей» колонки.

| `eyebrow-gap` | 8px | Eyebrow → заголовок |
| `card-gap` | 10–14px | Между элементами внутри карточки |
| `grid-gap` | 1px | Сетки «с сеткой линий» (см. ниже) |
| `price-gap` | clamp(12, 2vw, 20)px | Между карточками тарифов |

### Сетки

Приём «линии-разделители»: grid с `gap: 1px`, фон грида = `line`, фон ячеек = `bg`. Даёт таблично-модульную сетку без двойных бордеров.

| Блок | Desktop | Mobile (≤860px) |
|---|---|---|
| Bento применений | 6 колонок, карточки span 2/3/4 | 1 колонка |
| Боли | 3 колонки | 1 колонка |
| Конвейер | 4 колонки | 2 колонки |
| Тарифы | 3 колонки | 1 колонка |
| Статистика hero | 4 колонки | 2 колонки |
| Таблица сравнения | min-width 720px | горизонтальный скролл |

Брейкпоинт SELL: **860px**. Брейкпоинт BASE: **600px**.

## 4. Классификация блоков (компоненты)

Секции имеют якоря — на них можно ссылаться в правках: `#hero`, `#pain`, `#process`, `#uses`, `#compare`, `#price`, `#faq`, `#contact`.

### 4.1 Навигация `nav`
Sticky, фон `rgba(10,10,10,0.92)` + blur 8px, нижняя граница `line`.
Состав: `nav-author` (Oswald) · `nav-link` ×N (Courier, muted→fg) · `nav-cta` (лайм-кнопка).

### 4.2 Hero `#hero`
Высота ≥88vh, radial-свечение лайма справа сверху (7%).
Состав: `hero-eyebrow` (Courier + лайм-черта 28×2px слева) → `hero-h1` (3 строки, маска-reveal, последняя строка лаймом) → `hero-sub` → `hero-ctas` (btn-primary + btn-ghost) → `hero-stats` (4 ячейки: `hero-stat-val` + `hero-stat-label`).

### 4.3 Бегущая строка `marquee`
Границы сверху/снизу `line`. Oswald 18→30px; каждый второй элемент — контурный (`-webkit-text-stroke: 1px faint`, прозрачная заливка). Разделитель — лаймовая точка `●`. Скорость 28s linear.

### 4.4 Шапка секции `SectionHead`
`section-eyebrow` (Courier, **лайм**, формат `NN / название`) + `section-title` (H2) [+ `section-lead`].
Нумерация секций сквозная: 01 знакомо? · 02 почему быстрее · 03 применения · 04 честная математика · 05 тарифы · 06 вопросы · 07 кто делает.

### 4.5 Карточки

| Компонент | Состав | Особенности |
|---|---|---|
| `pain-card` | label (Courier faint) + title (H3) + text | статичная |
| `pipe-step` | num (Courier **лайм**) + title (H3-small) + text | статичная |
| `use-card` | num (Display, faint) + title (H3) + text + who | hover: фон `#111309`, номер → лайм; `who` с лаймовой стрелкой `→` |
| `price-card` | name + val (Display, «от» суперскриптом faint) + term (Courier лайм) + list (тире-буллеты лаймом) + cta | hover: подъём −4px; `featured`: лаймовый бордер + `price-badge` (лайм-плашка в углу) |
| `price-upsell` | title + text + val (лайм) | пунктирный бордер `dashed faint` |

### 4.6 Таблица сравнения `compare`
Шапка — Oswald; первая колонка — Courier faint; ячейки — Arial muted.
Колонка `.me`: фон лайм 6%, заголовок лаймом, текст белым.

### 4.7 FAQ `faq-item`
Вопрос — Oswald 16→26px, справа `+` лаймом (поворот 45° при открытии).
Ответ — Body-card, раскрытие по высоте 0.4s. Открыт максимум один.

### 4.8 Финальный CTA `#contact`
Grid `фото | текст`. Фото 120→220px, **grayscale 100%**.
Состав: eyebrow → H2 (часть лаймом) → текст → btn-primary + `final-note` (Courier faint).

### 4.9 Кнопки

| Кнопка | Стиль | Hover |
|---|---|---|
| `btn-primary` | лайм-фон, чёрный текст, Oswald, паддинг 14–18 / 24–40 | подъём −3px + лайм-тень |
| `btn-ghost` | прозрачная, бордер 1px fg, Oswald | инверсия (белый фон) |
| `nav-cta` | лайм, Courier, компактная | подъём −2px |
| `price-cta` | бордер 1px, Courier | инверсия; в featured — лайм-фон |

Текст кнопок заканчивается `→` там, где действие ведёт наружу (Telegram).

### 4.10 Футер
Одна строка: `© год имя` ←→ `Telegram → @mishegface`. Courier faint, ссылка при hover — лайм.

## 5. Графика и знаки

- **Иконок нет.** Вся графика — типографика и линии.
- Маркеры: `●` (лайм, marquee), `—` (лайм, списки), `→` (лайм, направления/CTA), `+` (лайм, FAQ), `○`/`●` (статусы, BASE).
- Фото: всегда **ч/б** (grayscale 100%), object-position `center 15%`.
- Фоновые эффекты: radial-свечение лайма (SELL hero), WebGL-дым (BASE hero).

## 6. Моушен

| Параметр | Значение |
|---|---|
| Easing (всё) | `cubic-bezier(0.16, 1, 0.3, 1)` — easeOutExpo |
| Reveal карточек | fadeUp: opacity 0→1, y 24→0, 0.7s, stagger 0.08s |
| Заголовки | maskUp: выезд из-под маски снизу (y 110%→0), 0.9s |
| Nav | падение сверху, 0.6s |
| Hover-переходы | 0.15–0.3s |
| Marquee | 28s, linear, бесконечно |
| FAQ | высота, 0.4s |
| Триггер scroll-reveal | однократно, за 40px до входа во вьюпорт |
| Reduced motion | все анимации отключаются (`prefers-reduced-motion`) |

**Характер:** сдержанно, без отскоков и пружин. Только смещение, маска и прозрачность.

## 7. Как ссылаться в правках

Формат: **страница → секция → компонент → элемент**. Примеры:

- «SELL, `#uses`, use-card 04, текст — сократи вдвое»
- «SELL, `#price`, featured-карточка, badge — поменяй текст»
- «токен `accent` → `#B8FF20` везде»
- «H2 / Section: уменьшить max до 72px»
- «BASE, cover, фото — убрать grayscale»
